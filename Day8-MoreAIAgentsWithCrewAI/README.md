## The official repository for production-ready, multi-agent workflows is the GitHub 
- [crewAIInc/crewAI-examples repository](https://github.com/crewAIInc/crewAI-examples)

### The primary official examples are categorized into core orchestration patterns:
 #### 🚀 Production Crews
- Marketing Strategy: crewAI-examples/marketing_strategy— Automates role-playing multi-agent marketing
- Trip Planner: crewAI-examples/trip_planner — Coordinates autonomous agents to source logistics, maps, and local activities.
- Stock Analysis: crewAI-examples/stock_analysis — Runs financial analysis agents utilizing real-time tool querying.
- Game Builder Crew: crewAI-examples/game_builder — A software development crew that collaboratively designs and codes complete Python games.
 #### 🔄 Multi-Agent Flows (State & Routing)
- Write a Book: crewAI-examples/flows/write_a_book — Employs asynchronous flows to generate parallel book chapters simultaneously.
- Self Evaluation Loop: crewAI-examples/flows/self_evaluation — Orchestrates iterative content generation loops checking outputs against performance criteria before final delivery.
- Meeting Assistant Flow: crewAI-examples/flows/meeting_assistant — Collects text or audio feeds, extracts action steps, and pipes outputs into Slack and Trello
